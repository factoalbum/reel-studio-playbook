# Captions, comment replies and posting

## Caption format (lowercase Roman Hinglish)

```
<hook line> 👇

1️⃣ <step>
2️⃣ <step>
3️⃣ <step>

honest note ⚠️ <limit, cost or update with the date checked>

poora setup chahiye? comment karo "KEYWORD" 💬 ya link in bio pe KEYWORD type karo 🎁
<one question for the comments> 👇

[search phrase, search phrase, search phrase, ...]

#internetoolbox #<topic> #<topic> #<topic> #<topic>
```

## Comment replies (Instagram DMs are restricted, so no DMs)

Reply under each keyword comment, a different wording each time, for example:
- "@name our DMs are paused right now 😅 Bio link has it all: tap the first link. Follow @internetoolbox for more free AI tools 🙌"
- "@name hamare DMs abhi band hain 😮 Bio link pe first link kholo, poora setup wahin hai. Follow @internetoolbox for more 🙌"
