# Captions, tags, comment replies and posting

## Instagram and Facebook caption (lowercase Roman Hinglish, the owner's style since 17 Nov 2026)

The style copies what works for fast-growing Hinglish tech creators: a hook, steps, a keyword, a question, a
block of search phrases, 5 hashtags.

```
<hook line with an emoji> 👇

1️⃣ <step>
2️⃣ <step>
3️⃣ <step>

honest note ⚠️ <limit, cost or update, with the date checked>

poora setup chahiye? comment karo "KEYWORD" 💬 ya link in bio pe KEYWORD type karo 🎁
<one question for the comments> 👇

[search phrase, search phrase, search phrase, ...]

#internetoolbox #<topic> #<topic> #<topic> #<topic>
```

Rules:
- Exactly 5 hashtags, the first is always `#internetoolbox`.
- The search-phrase block: 5 to 15 phrases people really type ("claude code free mein kaise chalaye",
  "gta 6 release date", "free ai tools hindi").
- Keep honest notes and on-screen corrections in the caption too.
- Never promise a DM. Never promise income ("results vary" when money is the topic).
- No em dash, en dash or ellipsis.
- Save the caption as `<reel file name>.caption.txt` next to the MP4.

## YouTube Shorts

- Title: Hinglish hook + topic + `#shorts`, under 100 characters. Example:
  "GTA 6 clipping se paise? Real rate, 4 steps aur 2 traps #shorts".
- Description: the same caption. **No external links**: YouTube refuses to save a description with a link until
  the channel finishes its one-time verification. Write "Google pe 'Internet Toolbox <topic>' search karo".
- Tags: 10 keyword tags (the search phrases).
- Settings: language Hindi, not made for kids, altered or synthetic content "No" (our animation is clearly
  animation), our own cover as the thumbnail.

## Posting (only with the owner's yes for that exact post and time)

- Facebook + Instagram: one Meta Business Suite upload posts or schedules both. Best time for our audience:
  about 7:30 PM IST (Instagram's Planner said followers are most active around 9:30 PM).
- Business Suite gotchas: the cover upload is on the Create step (Thumbnail > "Upload image" tab > "Upload image"
  link). "Next" and "Schedule" sit in the same spot, so never double-click. Time fields are segmented: click the
  hour and type it, click the minutes and type them, click AM/PM and type "p".
- After scheduling, confirm in the Planner.

## Comment auto-reply (Manychat, free plan)

Every reel with a keyword gets a Manychat automation **after the reel is live** (the free plan can only pick a
specific, already-published post; "any post" and "next post" need a paid plan, never upgrade).

1. Manychat > Automation > New Automation > "Auto-DM links from comments".
2. "a specific post or reel": pick the new reel.
3. "a specific word or words": the keyword in 2 or 3 spellings, comma separated (`GTA6, GTA 6, gta6`).
4. Turn on "reply to their comments under the post" and write **3 different public replies**. Our Instagram
   DMs are restricted, so the public reply must point to the bio link, not to the DMs. Example:
   - "Thanks bhai! 🎮 Bio link kholo, GTA6 type karo, poora clipping plan wahan hai"
   - "GTA6 plan ready hai 🔥 Profile ke link pe GTA6 type karo"
   - "Mil gaya! 🎮 Bio link mein GTA6 type karo, 4 steps aur scam check sab wahan"
5. The free plan forces "a DM with a link": write one line and add the article link as the button (it is sent
   if Instagram allows the DM).
6. Read every field back before Go Live: browser typing sometimes drops a letter ("aur" became "au").
7. Go Live, then check the automation shows LIVE.

## Checking and answering comments by hand

- YouTube: Studio > Community > Comments, filter "Unresponded".
- Facebook and Instagram: Business Suite > Inbox > "Facebook comments" and "Instagram comments". A comment with
  "View replies (1)" is already answered.
- Reply under each keyword comment with a different wording each time, pointing to the bio link. If the same
  person repeats the keyword many times, one reply is enough.
- Ask the owner before posting a reply that is not a keyword reply (questions, criticism, anything new).
