# Reel script

1. Read `AGENTS.md`, `docs/script-and-hooks.md` and `docs/honesty-rules.md`.
2. Pick one useful thing to teach. If the owner gives reference reels, take only the format and the topic. Write
   new words, a new angle and something they did not have (usually the real numbers and the catch).
3. Check every fact on the official source. Keep a list: fact, source URL, date checked.
4. Write the script with time marks: `[Hook, 0-3 s]`, `[3-10 s]`, ... About 2.6 spoken words per second.
5. End with: "Comment karo KEYWORD, ya link in bio pe KEYWORD type karo." Pick a new keyword.
6. Under the script, list: the facts with sources, the planned visuals per section (original, no third-party art),
   and anything the owner must decide.
7. Show it to the owner. The owner records it, or asks for a Gemini TTS voice (Puck; skits: You = Puck, Claude = Charon), see `docs/voice-gemini-tts.md`. Never clone a real person's voice.
