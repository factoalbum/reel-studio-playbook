# Reel caption

1. Read `docs/captions-and-posting.md` and `docs/honesty-rules.md`.
2. Use the format there exactly: hook + 👇, numbered steps, honest note with the date checked, keyword CTA (comment
   or type at the link in bio, never a DM promise), one question, a bracketed list of 10 to 15 search phrases,
   5 hashtags starting with #internetoolbox.
3. Facts and numbers must match the reel and its sources. Fix anything the voice got wrong, with "update 📌".
4. Comment replies: a different wording for each person, no DM promises, point to the first link in the bio.
5. Give the text to the owner. Do not post it unless the owner says yes for that post.
